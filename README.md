# توك توك الحارة 3D — نسخة الويب الأولية

## الملفات
- `index.html`: اللعبة كاملة في ملف واحد.

## طريقة الإضافة إلى GitHub
1. افتح مستودع `tuktuk-alhara-3d`.
2. اضغط **Add file** ثم **Upload files**.
3. فك ضغط الملف المرفق وارفع `index.html` مباشرة إلى جذر المستودع (Root)، وليس داخل مجلد فرعي.
4. اضغط **Commit changes**.

## تشغيل GitHub Pages
1. افتح **Settings** داخل المستودع.
2. اختر **Pages**.
3. في **Build and deployment** اختر **Deploy from a branch**.
4. اختر الفرع `main` والمجلد `/ (root)` ثم **Save**.
5. انتظر حتى يظهر رابط الموقع في صفحة Pages.

## ملاحظات
- اللعبة تستخدم مكتبة Three.js من CDN، لذلك يلزم اتصال إنترنت عند فتحها.
- التحكم على الهاتف من أزرار الشاشة، وعلى الكمبيوتر من W/A/S/D أو الأسهم.
- هذه نسخة أولية قابلة للتجربة وليست إصدارًا نهائيًا؛ خريطة الشوارع الحالية تخيلية مبسطة وليست مطابقة لخريطة المرج الفعلية.
